# Rossmann Store Sales – Deep Neural Network

This repository contains my deep learning solution for the
[Kaggle Rossmann Store Sales](https://www.kaggle.com/c/rossmann-store-sales) competition.

The project uses TensorFlow/Keras to build a deep neural network
for forecasting daily sales of 1,115 Rossmann stores across Germany.
The model combines calendar features, competition and promotion data,
store-level aggregates, and lag/rolling time–series features.
